# Tier 2 City Population Profile

## Demographics
- **Setting:** Mid-sized cities experiencing growth.
- **Occupations:** Manufacturing, local retail, education, government jobs.
- **Traits:** Aspirations for upward mobility, cost-conscious, strong family ties.
- **Behavior in Simulation:** React strongly to economic incentives, less digitally engaged than Tier 1 but growing rapidly, value stability.

## Typical Agents
1. **The Government Employee:** Stable, risk-averse.
2. **The Factory Worker:** Hard-working, affected by macroeconomic trends.
3. **The Retail Store Owner:** Deeply embedded in the local economy.
